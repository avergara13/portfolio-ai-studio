# Portfolio AI Studio

Google AI Studio design sandbox for Angel Vergara’s recruiter-facing AI workflows and systems portfolio.

## Purpose

This repository preserves experimental visual directions, layout concepts, and presentation-system prototypes developed in Google AI Studio.

It is not the production portfolio source of truth.

Production implementation is maintained separately in the governed portfolio repository.

## Integration rule

Visual concepts may be selectively ported into the production Next.js source after review.

Prototype techniques such as compiled-HTML patching, DOM injection, and generated-export CSS overrides should not be merged wholesale into production.
