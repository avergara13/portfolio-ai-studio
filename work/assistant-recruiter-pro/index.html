THE SEARCH PROBLEM

A job description rarely maps cleanly to one search query. Titles vary, required skills overlap with adjacent roles, exclusions matter, and an apparently valid Boolean string can still produce poor candidates.

01 INPUT

Job Description

02 PARSE

Constraints

03 LOGIC

Query Strategy

Search Results

05 HUMAN REVIEW

Relevance Review

06 UPDATE

Revision

From a messy job description to a reviewable search strategy.

The generated query is an intermediate artifact; relevance feedback determines whether the strategy should be preserved, narrowed, expanded, or revised.

SANITIZED INPUT CONSTRAINTS

Senior Software Engineer Distributed Systems No frontend

GENERATED BOOLEAN · STRATEGY PROPOSAL

("senior software engineer" OR "backend engineer") AND ("distributed systems" OR "golang")

ILLUSTRATIVE HUMAN REVIEW · EVALUATION BOUNDARY

("senior software engineer" OR "backend engineer") AND ("distributed systems" OR "golang")
Reviewer feedback: Getting too many full-stack candidates. Add explicit exclusions for React/Frontend.

REVISED QUERY STATE · INCORPORATING FEEDBACK

("senior software engineer" OR "backend engineer") AND ("distributed systems" OR "golang") -("react" OR "frontend" OR "css")

Relevant profiles False positives Missing target profiles Platform realism Constraint adherence
